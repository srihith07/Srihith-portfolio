Research · Submitted to JMIR Mental Health01 / 03

MAGIPLUS — Multi-Agent Psychiatric Assessment

Extended the MAGI research framework with five modules: emotion tracking, PHQ-9/GAD-7/C-SSRS severity scoring, a tiered recommendation agent with crisis escalation, longitudinal memory, and clinical report generation. Achieved 90% diagnostic accuracy and 100% crisis recall across 10 simulated cases. The work was submitted to JMIR Mental Health.

Retrieval-augmented generation02 / 03

RAG PDF Assistant

Built a local-first retrieval-augmented generation application that answers questions about PDF documents with page-level citations. Implemented PDF extraction, page-aware text chunking, and local embeddings using pdfplumber and all-MiniLM-L6-v2. Integrated ChromaDB and the Google Gemini API with citation-based retrieval and hallucination guardrails to improve answer traceability.
